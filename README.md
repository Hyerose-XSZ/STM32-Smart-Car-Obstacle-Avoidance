# STM32F103 智能避障小车 (寄存器版本)

本项目基于 **正点原子 STM32F103ZET6 精英板**、**L298N 电机驱动模块** 与 **HC-SR04 超声波测距传感器**，采用**纯寄存器级代码**实现 PWM 差速调速、超声波测距以及自主避障停车功能。

---

## 一、 硬件引脚连接表

### 1. L298N 电机驱动接线
| L298N 引脚 | STM32 引脚 | 引脚模式 / 定时器 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **ENA** | `PA6` | 复用推挽 (`TIM3_CH1`) | 左侧电机 PWM 调速 (0~1000) |
| **ENB** | `PA7` | 复用推挽 (`TIM3_CH2`) | 右侧电机 PWM 调速 (0~1000) |
| **IN1** | `PA0` | 通用推挽输出 | 左轮方向控制 |
| **IN2** | `PA1` | 通用推挽输出 | 左轮方向控制 |
| **IN3** | `PA4` | 通用推挽输出 | 右轮方向控制 |
| **IN4** | `PA5` | 通用推挽输出 | 右轮方向控制 |
| **GND** | `GND` | 共地 | **必须与单片机共地** |

### 2. HC-SR04 超声波测距接线
| 超声波引脚 | STM32 引脚 | 引脚模式 | 功能说明 |
| :--- | :--- | :--- | :--- |
| **Trig** | `PB10` | 通用推挽输出 (50MHz) | 发送 20us 高电平触发测距 |
| **Echo** | `PB11` | 下拉输入 (Input Pull-down) | 接收回响脉冲 (`TIM4` 硬件微秒计时) |
| **VCC**  | `5V`   | 外接电源 | **必须接 5V 供电**（接 3.3V 探头无法起振） |
| **GND**  | `GND`  | 共地 | 信号地 |

### 3. 板载外设与状态指示
* **LED0 (`PE5`)**：状态指示灯（低电平点亮，高电平熄灭）。用于超声波异常闪烁报警及近距离避障常亮指示。
* **蜂鸣器 (`PB8`)**：代码中已做初始化并默认强制拉低（输出 0），彻底消除引脚悬空带来的误鸣。

## 二、 代码文件结构与说明

本项目包含从底层电机驱动到软硬件联调的各个阶段代码：

### 1. `四轮前进.c`（阶段一：基础电机驱动验证）
* **功能说明**：最基础的 GPIO 电平控制，使能双侧电机驱动，驱动小车匀速前进。
* **主要验证**：排查 L298N 供电、逻辑引脚接线方向以及轮子正反转逻辑是否正确。

### 2. `差速测试.c`（阶段二：TIM3 硬件 PWM 差速转向）
* **功能说明**：配置 `TIM3` 通道 1 (`PA6`) 与通道 2 (`PA7`) 输出 1kHz 硬件 PWM，实现左右轮独立调速。
* **主要验证**：测试 `Motor_SetSpeed(speedLeft, speedRight)` 差速转弯控制，支持前进、后退、原地旋转与刹车。

### 3. `超声波模块测试（配合LED灯）.c`（阶段三：传感器独立硬件诊断）
* **功能说明**：**完全不启动电机**，排除电机启动大电流干扰，专用于排查超声波模块与接线是否完好。
* **诊断指示**：
  * **LED0 快速闪烁**：硬件故障 / 供电不足 5V / 超声波未收到回波。
  * **手靠近探头 10cm 内 LED0 常亮，拿开后熄灭**：说明超声波模块完好，测距功能 100% 正常。

### 4. `超声波测距停车.c`（阶段四：软硬件系统级集成避障）
* **功能说明**：将超声波测距与电机 PWM 调速融合。正前方障碍物距离 $\le 5\text{ cm}$ 时，小车立即紧急刹车停车；障碍物移开后自动恢复巡航直行。
* **调试支持**：包含全局变量 `volatile float current_distance`，支持在 Keil Debug 窗口中实时监视距离数值。

## 三、 硬件调试与避坑要点

1. **超声波引脚冲突避坑**：
   * 严禁将超声波接在 `PB8`（板载蜂鸣器）或 `PB5`（板载 LED1），否则会导致蜂鸣器长鸣或触发脉冲被电路下拉钳位。本项目已统一切换为纯净 GPIO `PB10` 与 `PB11`。
2. **共地原则**：
   * L298N 驱动板的 GND、超声波模块的 GND 必须与 STM32 开发板的 GND 紧密相连。
3. **超声波供电**：
   * HC-SR04 必须保证 5V 充足供电，若通过 USB 供电导致探头无法起振，需外接稳压电源。

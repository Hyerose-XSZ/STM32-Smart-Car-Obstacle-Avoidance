# STM32F103 智能避障与循迹小车 (寄存器版本)

本项目基于 **正点原子 STM32F103ZET6 精英板**、**L298N 电机驱动模块**、**HC-SR04 超声波测距模块** 与 **4 路红外循迹传感器**，采用**纯底层寄存器级代码**构建。系统集成了 1kHz 硬件 PWM 差速调速、高精度超声波微秒测距、低速电机死区补偿、大曲率弯道历史记忆抗冲线自救以及紧凑型小夹角避障绕行等功能。

| 超声波引脚 | STM32 引脚 | 引脚模式 | 功能说明 |
| :--- | :--- | :--- | :--- |

### 4. 板载外设与状态指示
* **LED0 (`PE5`)**：状态指示灯（低电平点亮）。用于避障触发阶段常亮提示、超时脱线报警快闪。
* **蜂鸣器 (`PB8`)**：代码初始化时强制拉低置 0，彻底消除引脚悬空带来的误鸣。
* **微秒基准定时器 (`TIM4`)**：配置为 1MHz 计数（1us/Tick），专门为超声波脉冲计时与底层延时提供高精度基准。

## 二、 代码文件结构与说明

本项目根据功能模块解耦与渐进式开发原则，划分了各个阶段的测试与集成代码文件：

### 1. `四轮前进.c`（基础电机驱动验证）
* **功能说明**：最基础的双侧电机 GPIO 电平控制。
* **主要验证**：排查 L298N 供电线路、逻辑引脚接线方向以及双侧车轮正反转极性是否一致。

### 2. `差速测试.c`（TIM3 硬件 PWM 差速调速）
* **功能说明**：配置 `TIM3` 通道 1 (`PA6`) 与通道 2 (`PA7`) 输出 1kHz 硬件 PWM。
* **主要验证**：实现 `Motor_SetSpeed(speedLeft, speedRight)` 函数，测试左右轮独立调速、原地自转及差速过弯性能。

### 3. `循迹.c`（4 路红外自主循线）
* **功能说明**：实现 4 位红外探头（PC0~PC3）的状态机扫描与差速转向修正。
* **主要验证**：验证直行居中、微偏微调、急弯大差速打舵以及应对大曲率弯道的稳定性，锁定基准巡航速度。

### 4. `超声波模块测试（配合LED灯）.c`（传感器独立硬件诊断）
* **功能说明**：**完全不启动电机**，排除电机启停瞬间的大电流反峰干扰。
* **诊断指示**：
  * **LED0 快速闪烁**：硬件故障 / 供电不足 5V / 超声波未收到有效回波。
  * **手靠近探头 10cm 内 LED0 常亮，移开后熄灭**：证明超声波模块驱动与微秒脉宽捕获 100% 正常。

### 5. `超声波测距停车.c`（静态遇障紧急制动）
* **功能说明**：小车直线巡航，前方检测到障碍物距离 $\le 5	ext{ cm}$ 时立即刹车停车；障碍物移开后自动恢复前行。
* **主要验证**：验证超声波在动态行进中的测距稳定性以及紧急刹停的响应延迟。

### 6. `循迹+超声波停车.c`（循线巡航与动态防撞集成）
* **功能说明**：将 4 路红外循迹与超声波测距融合。小车沿黑线自主巡线，当前方轨道出现障碍物时，立即暂停电机循线并在原地刹停等待；障碍物移走后自动无缝继续循线。

### 7. `避障绕行.c`（小夹角绕障姿态单项标定）
* **功能说明**：**剥离常规循迹控制**，专用于单项标定小车的绕障轨迹与动作时间。
* **主要验证**：小车遇障后依次执行“平缓右出 $
ightarrow$ 纵向超越 $
ightarrow$ 小夹角左回切 $
ightarrow$ 探头抓线 $
ightarrow$ 主动向右顺线拉正”，抓到黑线并拉直车身后**立即原地刹停锁死**，便于肉眼观察入轨姿态与切角是否达标。

### 8. `循迹+避障绕行1.0.0.c`（全闭环自主巡航与避障系统）
* **功能说明**：将验证成熟的循迹逻辑与避障绕行流程深度融合。
* **运行机制**：平时以固定速度稳定循线；遇障触发紧凑绕行，绕过障碍重新捕获黑线后，自动切换回常规循线状态，实现无需人工干预的自主避障闭环。

### 9. `循迹+避障绕行2.0.0（可行未知）.c`（实验性优化版本）
* **功能说明**：在 1.0.0 基础上的前沿实验版本。
* **探索方向**：用于探索更高巡航速度下的动态参数匹配、尝试更激进的回切打舵策略或测试大曲率弯道中的极端避障工况，作为代码迭代与对比测试的备用分支。

## 三、 近期核心攻关与算法改进说明

### 1. 低速电机死区与“打圈死锁”修复
* **现象**：当巡航速度降至 300 后，小车转弯时内侧轮因设速过低导致起动转矩不足，直接在机械死区卡死堵转，小车以单轮为圆心持续原地打转。
* **改进**：
  * 重新测定电机有效起步阈值，取消单侧反向反转策略，改用**正向动力阻尼（内侧轮保留有效转速）**。
  * 确保左右轮差速比既能提供充足的偏航力矩，又绝不陷入电机死区。

### 2. 绕障紧凑化与切回小夹角顺线算法
* **现象**：早期避障采用原地自转（`SPIN`），车身右甩过猛（偏出跑道 60° 以上），纵向绕行距离长；切回黑线时车身接近垂直撞线，惯性导致直接冲出对侧白地。
* **改进方案（五阶段轨迹控制）**：
  1. **微幅弧线脱轨**：将右转改为单侧差速圆弧偏转（`左460, 右130`，持续 150ms），右转角严格收窄在 **20°~25°**。
  2. **紧凑平行超越**：将纵向超越时间从原先的 700ms 压缩至 **480ms**（巡航速度 300），紧贴障碍物外沿快速通过。
  3. **小夹角回切导向**：左打舵 380ms（内侧轮降至 60 维持转向扭矩），使车体以约 **20°~30° 的极小锐角**斜向切入跑道。
  4. **双重采样防抖寻线**：寻线阶段要求探头**连续 2 次采样（20ms）稳定确认**踩中黑线，彻底过滤白地杂波干扰。
  5. **触线主动顺平拉直**：在探头踩线的瞬间，立即施加 120ms 的**主动右偏动作（`左480, 右150`）**，在动量上抵消向左冲力，车身在触线瞬间与黑线平行并轨。

### 3. 大曲率缓弯/长弯抗冲线与“丢线自救”机制
* **现象**：面对曲率半径较大的缓长弯道，小车累积转向角速度跟不上弯道延伸速度，外侧探头脱线后瞬间进入 `0b0000`（全白地），原程序减速直行导致小车沿弯道切线飞出赛道。
* **改进方案**：
  * **偏航历史记忆（`last_dir`）**：在每次有效打舵时记录偏航方向（1: 偏右, 2: 偏左）。
  * **单侧大扭矩搜线**：当进入 `0b0000`（完全失线）时，小车依照 `last_dir` 的记忆方向，维持单侧轮高速推进（`520, 0` 或 `0, 520`），主动沿最后脱轨方向扫线自救，0.2 秒内迅速重捕黑线。

## 六、 硬件调试与避坑要点

1. **超声波引脚冲突**：
   * 严禁将超声波引脚分配到 `PB8`（板载蜂鸣器）或 `PB5`（板载 LED1），否则会引起蜂鸣器长鸣或触发信号电平被下拉钳位。本项目已统一定位到纯净 GPIO `PB10` (Trig) 与 `PB11` (Echo)。
2. **共地原则**：
   * L298N 驱动板的逻辑地、红外循迹模块的地、超声波模块的地必须与 STM32 开发板的 GND 汇流连接，保证逻辑电平参考一致。
3. **超声波供电规范**：
   * HC-SR04 探头压电陶瓷起振必须保证稳固的 5V 供电；若通过单片机 3.3V 引脚供电会导致超声波发射距离极短或无法产生 Echo 脉冲。
4. **电池压降补偿**：
   * 当电池电量下降时，电机转速降低可能导致同一延时下的偏角减小。若发现避障回切角度不足，可将 `TIME_TURN_LEFT` 适度延长（如从 380ms 增加到 420ms）。

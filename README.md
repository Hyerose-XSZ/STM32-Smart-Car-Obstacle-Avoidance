# STM32F103 智能避障与高速循迹小车 (寄存器版本)

本项目基于 **正点原子 STM32F103ZET6 精英板**、**L298N 双 H 桥电机驱动模块**、**HC-SR04 超声波测距传感器** 与 **4 路红外光电循迹模块**，采用**纯底层寄存器级代码**构建[cite: 2]。

系统实现了 **机械底盘搭建与电气拓扑隔离**、**极速直道冲刺 (PWM 450)**、**入弯断崖式自适应动量抑制**、**急弯主动向心反拉力矩**、**历史偏航记忆抗冲线自救**，以及**带主动倒车缓冲与大横向安全净距的复合闭环避障状态机**[cite: 2]。本文档系统复盘了从零开始的硬件选型装配、模块级递进调试、底层驱动排障、控制方案演进以及核心参数全覆盖标定手册[cite: 2]。

## 一、 机械组装与硬件电气连接

### 1. 机械结构布局与走线规范
* **底盘结构**：双后轮直流减速电机（带测速码盘减速箱）驱动，重心保持在底盘中后轴上方 20mm 处，防止高速刹车点头翻车。
* **红外传感器支架**：4 路探头水平等间距横向排布在前轴前方 35mm 处，对地垂直离地间距卡控在 **8mm ~ 12mm**。过高导致反射光斑弥散，过低在下坡颠簸时易蹭地受损[cite: 2]。
* **超声波安装**：使用电工胶带安装于车头正前方正中，水平俯仰角校准为 $0^\circ$（严格水平），高度离地约 45mm，防止发射的声波波束地面反射（地杂波）导致误判障碍物。
* **强弱电隔离布线**：
  * 电机动力线（高频大电流、含电感反峰）与单片机 GPIO 信号线、超声波 Echo/Trig 信号线严格分道走线，禁止平行绑扎。
  * L298N 的 Logic GND、单片机 GND、红外模块 GND 与动力电池负极采用**星型单点汇流共地**，彻底消除地回路阻抗耦合噪声[cite: 2]。

### 2. 核心供电拓扑设计
* **动力源**：采用 2 节 18650 串联动力锂电池组（标称 7.4V，满电 8.4V）。
* **驱动供电**：电池正极直连 L298N 的 12V 动力输入端（VCC）；L298N 内部开启 78M05 稳压芯片，拔下板载 5V 跳线帽隔离外部干扰，使用独立 5V 稳压为 HC-SR04 提供强劲供电。
* **单片机供电**：开发板采用专用降压稳压模块或独立 5V 电源接口供电，保证 STM32 内核 3.3V 逻辑电平稳定，避免电机堵转瞬态压降引发系统欠压复位（BOD）。

## 四、 控制方案选择与技术路线深度对比

在系统开发演进过程中，针对循迹与避障的核心技术路线进行了多轮实车实地测试对比：

| --- | --- | --- | --- | --- |
| **方案 A：离散逻辑查表法** | 纯读取当前红外状态，硬编码给定左/右轮固定差速 | 极低（上限约 260），直道频繁剧烈左右“画龙”抖动 | 惯性过大，急弯动力不连续，直接冲出赛道 | 淘汰（仅用于硬件连通性初检）

## 五、 核心技术攻关与软硬件故障诊断记录

### 1. 电机驱动底层 `GPIOA->CRL` 掩码重叠配置陷阱

* **故障现象**：程序烧录后，板载测试代码正常，但车轮出现“右轮转速正常，左轮完全停转”，或者“只有单侧电机产生高频电磁啸叫却无动力”。
* **根因定位**：`Motor_Init()` 在配置 `GPIOA->CRL` 寄存器时，清零掩码操作与复用功能配置发生错位覆盖：
```c
// 错误历史代码：未能清零 PA6 对应控制位，导致按位或写入产生逻辑混叠
GPIOA->CRL &= 0x0000FF00;
GPIOA->CRL |= 0xBB330033;

```


该错误导致控制左轮 PWM 的 `PA6`（`TIM3_CH1`）未能成功进入“复用推挽输出（`AF-PP`, `0xB`）”，引脚被内部下拉钳位在低电平，PWM 调速方波无法到达 L298N 的 ENA 端，左轮被彻底断电。


* **终极解决方案**：重构原子级寄存器配置，严格保证控制位彻底清零后再写入目标配置：
```c
GPIOA->CRL &= 0x0000FF00; // 彻底锁定对应控制位
GPIOA->CRL |= 0xBB330033; // PA0,PA1,PA4,PA5 为通用推挽 (0x3)；PA6,PA7 为复用推挽 (0xB)

```



### 2. 红外探头硬件级损坏诊断与软件容错策略

* **故障现象**：3 号红外探头（`PC1` / `IN3`）板载指示灯呈现“常亮或常灭”极端状态，拧动电位器无法实现感应跳变；导致在平整全白地上小车经常误判为踩线，左电机异常减速，小车严重向右偏航打转。
* **硬件诊断流程**：
1. 使用手机摄像头红外滤镜对准探头矩阵：1、2、4 号探头均呈现粉紫色红外光斑，而 3 号发射管完全无光，确诊发射二极管开路烧毁。


2. 拧动微调电位器时板载指示灯仍能被强行点亮或熄灭，证明 LM393 双电压比较器功能完好，故障完全局限在红外发射端。




* **软件容错处理**：在重构的 `Tracking_GetError()` 中建立状态容错映射，结合宽黑线（50~60mm 宽胶带）物理特性，依靠其余 3 颗正常探头重构非对称偏差闭环；并在脱线瞬间由 `memory_dir` 锁存历史偏航，彻底消除脏数据引起的单侧锁死。



### 3. 下坡长直道全速冲刺与小半径急弯（直角弯）的动力学矛盾

* **物理矛盾**：赛道存在下坡长直道紧接小半径急弯工况。当小车以 PWM 450 全速冲刺时，具有极大的直线切向动量。如果使用常规线性 PD，小车感知到偏航时的转向加速度远小于向心加速度需求，直接由于离心惯性冲出跑道。
* **解决方案（动量抑制与主动反拉机制）**：
* **断崖式自适应降速**：基础巡航设为 `SPEED_BASE = 450`；一旦探头感知到偏航，系统按斜率 `SPEED_DROP_RATE = 50` 断崖式下调基准速度，最低跌至 `SPEED_CURVE_MIN = 90`，在入弯前 10~20ms 内强制踩下“电磁刹车”。


* **急弯主动向心反拉**：当绝对偏差 $\vert{}Error\vert{} \ge 4.0$ 时，外侧轮施加 `380` 大扭矩推进，内侧轮施加 **`-180` 负向反转力矩**，强行将车头拉向弯道内侧，彻底克服甩尾惯性。


* **中弯动力阻尼**：当 $2.0 \le \vert{}Error\vert{} < 4.0$ 时，内侧轮施加 `-90` 阻尼，消除切向冲出风险。





### 4. 避障动作横向剐蹭与回切冲线问题

* **物理矛盾**：原避障逻辑在检测到距离 $\le 12\text{ cm}$ 刹停后，由于直道 450 极速带来的刹车滑行惯性，小车停下时已经紧逼障碍物（不足 4cm）；此时向右打舵由于回转半径原因，车身右后侧高概率剐蹭障碍物；且回切至黑线时车体以接近 90° 垂直横穿黑线，直接冲出对侧白地。


* **解决方案（七阶段避障状态机）**：
* **双重制动与强制倒车缓冲**：触发避障后先刹车 150ms 吸收前冲动量，紧接着**强制倒车 150ms（`-450, -450`）**，主动拉开与障碍物纵向物理裕量，随后二次静止 100ms。


* **加大横向安全净距**：向右借道时间延长至 320ms，外侧与内侧形成大差速（`460, 80`），超越直行加长至 590ms，外展裕量增加 40% 以上，彻底杜绝蹭边。


* **小夹角回切与反向冲正**：回切前引入 20ms 瞬间反抽（`-300, 200`）破坏右向角动量，随后单侧轮平稳推进（`0, 460` 持续 430ms），使车身以 **$25^\circ \sim 35^\circ$ 的平缓小锐角**接触黑线；检测到撞线后立即执行 180ms 反向冲正（`260, 80`），与赛道切线顺平并轨。

## 六、 控制算法架构与参数标定手册

### 1. 动量抑制阶梯转向算法架构 (PID_Tracking_Loop)

系统采用连续误差映射结合分级力矩输出机制：

$$\text{Error} = f(\text{Sensor State})$$

$$\text{Current Base} = \max(\text{SPEED\ BASE} - |\text{Error}| \times \text{SPEED\ DROP\ RATE},\; \text{SPEED\ CURVE\ MIN})$$

$$\text{PID Output} = K p \times \text{Error} + K d \times (\text{Error} - \text{Last\ Error})$$

#### 工况 A：直道与微弯 (|Error| < 2.0)

$$\begin{cases} \text{Left Motor} = \text{Current Base} + \text{PID Output} \\ \text{Right Motor} = \text{Current Base} - \text{PID Output} \end{cases}$$

#### 工况 B：中度弯道 (2.0 <= |Error| < 4.0)

$$\begin{cases} \text{Left Motor} = \text{Current Base} + 120,\; \text{Right Motor} = -90 & (\text{Error} > 0) \\ \text{Left Motor} = -90,\; \text{Right Motor} = \text{Current Base} + 120 & (\text{Error} < 0) \end{cases}$$

#### 工况 C：急弯大弧线 (|Error| >= 4.0)

$$\begin{cases} \text{Left Motor} = 380,\; \text{Right Motor} = -180 & (\text{Error} > 0) \\ \text{Left Motor} = -180,\; \text{Right Motor} = 380 & (\text{Error} < 0) \end{cases}$$

## 八、 硬件工程落地避坑指南

1. **CRL 寄存器复用推挽覆盖规则**：
* 配置特定引脚模式前，必须对该引脚在 `CRL`/`CRH` 中的 4 个对应位（`MODE` 和 `CNF`）彻底清零。若直接执行按位或操作，会导致原寄存器残留的高电平位产生冲突，使复用推挽（`0xB`）退化为通用输入或开漏模式。




2. **超声波测距分频与循迹主频解耦**：
* HC-SR04 在检测到超距或无障碍物时，回波高电平最大持续时间可达数十毫秒。若直接置于循迹主循环中串行等待，会导致控制周期严重拉长，直接摧毁微分项（$K_d$）的时序连续性。


* **工程解法**：在主循环中设置计数器分频器，每迭代 10 次（约 30~40ms）执行一次测距，其余迭代专心维持 2ms 高频精确循迹。




3. **单片机与外设严格单点共地**：
* L298N 驱动板的强电地（GND）、电池负极、红外传感器地与单片机开发板的 GND 必须可靠物理互联。共地阻抗过大会导致电机启停的大电流在信号地线上产生几百毫伏的杂波反峰，导致单片机异常复位或超声波误判。




4. **探头离地垂直高度控制**：
* 4 路红外探头离地高度必须严格卡控在 **8mm ~ 12mm**。过高会导致反射光斑严重发散，信噪比恶化直接落入全白盲区；过低则易在下坡颠簸时撞击跑道机械断裂。


5. **动力电池供电内阻与压降补偿**：
* L298N 内部双极型达林顿管在饱和导通时存在约 1.5V~2.0V 的固有管压降。当电池放电至标称 7.4V 以下时，降速档位输出的实际端电压极低，易陷入静摩擦死区。赛道调试应确保电池电压维持在 **8.0V 以上**，以保证时间延时与转向角度的高度重合。

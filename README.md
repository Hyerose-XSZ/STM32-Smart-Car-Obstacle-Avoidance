# STM32F103 智能避障与高速循迹小车 (寄存器版本)

本项目基于 **正点原子 STM32F103ZET6 精英板**、**L298N 双 H 桥电机驱动模块**、**HC-SR04 超声波测距传感器** 与 **4 路红外光电循迹模块**，采用**纯底层寄存器级代码**构建。

系统实现了 **极速直道冲刺 (PWM 450)**、**入弯断崖式自适应动量抑制**、**急弯主动向心反拉力矩**、**历史偏航记忆抗冲线自救**，以及**带倒车缓冲与大横向安全净距的复合闭环避障状态机**。本文档记录了项目全生命周期的硬件接线、文件结构、底层故障排查、调参过程与控制方案选型对比。

## 三、 控制方案选择与技术路线对比

在系统开发演进过程中，针对循迹与避障的核心技术路线进行了多轮测试与对比决策：

### 1. 循迹控制策略对比

| 方案路线 | 动作特性 | 直道极速性能 | 急弯与长缓弯表现 | 最终选型决策 |
| --- | --- | --- | --- | --- |
| **方案 A：离散逻辑查表法** | 读传感器直接输出硬编码差速 | 极低（上限约 260），直道频繁剧烈左右晃动 | 急弯容易因动力不连续直接冲出 | 淘汰（仅用于前期单项连通性验证） |
| **方案 B：纯线性增益 PID** | 误差线性转换为 PWM 差速输出 | 适中（约 320），直道稳定性较好 | 进入急弯时无法抵消切向动量，甩尾严重 | 淘汰（无法兼顾长直道冲刺与锐角入弯） |
| **方案 C：断崖式降速 + 阶梯向心反拉 (当前方案)** | 直道高速，偏航断崖降速，大偏差施加负扭矩 | **极高（稳定 450）**，直道微调稳定不晃动 | **入弯瞬间强制制动，急弯内轮反抽，过弯精准** | **最终采用** |

### 2. 避障控制策略对比

| 方案路线 | 轨迹特征 | 空间占用 | 黑线重捕入轨姿态 | 最终选型决策 |
| --- | --- | --- | --- | --- |
| **方案 A：原地自转 (SPIN) 绕行** | 原地直角旋转，折线折返 | 横向过宽（>35cm），空间冗余严重 | 垂直冲撞黑线，直接穿出对侧白地 | 淘汰（动作生硬且极易冲线脱轨） |
| **方案 B：纯开环弧线借道** | 固定时间大弧度绕行 | 适中，但车头离障碍物过近易蹭边 | 依靠固定时间回切，受电池电压波动影响大 | 淘汰（环境适应性差） |
| **方案 C：倒车缓冲 + 宽距变道 + 复合回切闭环 (当前方案)** | 刹车倒车后撤，大角度侧展，斜向平缓搜线冲正 | **横向净距充裕，彻底避免剐蹭** | **小锐角切线入轨，反向打舵冲正，无缝衔接** | **最终采用** |

## 四、 核心技术攻关与软硬件故障诊断记录

### 1. 电机驱动底层 `GPIOA->CRL` 掩码重叠配置陷阱

* **故障现象**：烧录程序后出现“开机只有右轮旋转，左轮纹丝不动”或“特定状态下单侧锁死”。
* **根因定位**：`Motor_Init()` 初始化配置 `GPIOA->CRL` 时，清零掩码操作不彻底：
```c
// 错误历史代码：未能彻底清除 PA6 位段，导致模式配置位产生逻辑或叠加错位
GPIOA->CRL &= 0x0000FF00;
GPIOA->CRL |= 0xBB330033;

```


该错误导致控制左轮 PWM 的 `PA6`（`TIM3_CH1`）未能成功进入“复用推挽输出（`AF-PP`, `0xB`）”，引脚被单片机内部电路下拉钳死，PWM 驱动信号无法输出至 L298N 的 ENA 端。
* **解决方案**：重构原子级寄存器配置，严格保证控制位彻底清零后再写入目标模式：
```c
GPIOA->CRL &= 0x0000FF00; // 彻底锁定对应控制位
GPIOA->CRL |= 0xBB330033; // PA0,PA1,PA4,PA5 为通用推挽 (0x3)；PA6,PA7 为复用推挽 (0xB)

```



### 2. 红外传感器硬件级损坏诊断与容错隔离

* **故障现象**：3 号红外探头（`PC1` / `IN3`）背部指示灯在调节电位器时呈现“常亮或常灭”两极翻转，对黑白跳变无响应；导致小车在无遮挡全白地上误判有线，右轮直接减速停转。
* **硬件诊断流程**：
1. 使用手机摄像头红外模式观测探头：1、2、4 号探头均呈现粉紫色微弱红外光斑，而 3 号发射管完全无光，确诊发射二极管/限流电阻断路烧毁。
2. 拧动微调电位器时指示灯能在常亮与常灭间切换，证明板载 LM393 比较器芯片功能正常，故障严格局限在光电转换前端。


* **软件容错处理**：在重构的 `Tracking_GetError()` 中建立状态容错映射，结合宽赛道（宽 50~60mm）物理特性，依靠其余 3 颗正常探头重构非对称偏差闭环，并由 `memory_dir` 锁存历史偏航，彻底消除脏数据引起的单侧锁死。

### 3. 下坡长直道冲刺与小半径急弯（直角弯）的动力学矛盾

* **物理矛盾**：小车在下坡长直道全速（PWM 450）冲刺时，具有极大的直线切向动量。传统线性 PD 在进入弯道初期产生的转向力矩远小于离心力，导致小车径直飞出赛道。
* **解决方案（动量抑制与主动反拉机制）**：
* **断崖式自适应降速**：基础巡航设为 `SPEED_BASE = 450`；一旦探头感知到偏航，系统按斜率 `SPEED_DROP_RATE = 50` 断崖式下调基准速度，最低跌至 `SPEED_CURVE_MIN = 90`，在入弯前 10~20ms 内建立强制电磁制动。
* **急弯主动向心反拉**：当绝对偏差 $\vert{}Error\vert{} \ge 4.0$ 时，外侧轮施加 `380` 大扭矩推进，内侧轮施加 **`-180` 负向反转力矩**，强行将车头拉向弯道内侧，彻底克服甩尾惯性。
* **中弯动力阻尼**：当 $2.0 \le \vert{}Error\vert{} < 4.0$ 时，内侧轮施加 `-90` 阻尼，消除切向冲出风险。



### 4. 避障动作横向剐蹭与回切冲线问题

* **物理矛盾**：原避障在 12cm 触发后直接右打舵，高速刹车惯性导致小车滑至障碍物近前，车身右侧在变道时剐蹭障碍；回切黑线时因角速度过大，车体以接近 90° 垂直横穿黑线，直接冲出对侧白地。
* **解决方案（七阶段避障状态机）**：
* **双重制动与倒车缓冲**：触发避障后先刹车 150ms 吸收前冲动量，紧接着**强制倒车 150ms（`-450, -450`）**，主动拉开与障碍物的物理纵深。
* **加大横向安全净距**：向右借道时间延长至 320ms，超越直行加长至 590ms，外展裕量增加 40% 以上，彻底杜绝蹭边。
* **小夹角回切与反向冲正**：回切前引入 20ms 瞬间反抽（`-300, 200`）破坏右向角动量，随后单侧轮平稳推进（`0, 460` 持续 430ms），使车身以 **$25^\circ \sim 35^\circ$ 的平缓小锐角**接触黑线；检测到撞线后立即执行 180ms 反向冲正（`260, 80`），与赛道切线顺平并轨。

## 五、 控制算法架构与参数标定手册

### 1. 动量抑制阶梯转向算法架构 (PID_Tracking_Loop)

系统采用连续误差映射结合分级力矩输出机制：

$$\text{Error} = f(\text{Sensor State})$$

$$\text{Current Base} = \max(\text{SPEED\ BASE} - |\text{Error}| \times \text{SPEED\ DROP\ RATE},\; \text{SPEED\ CURVE\ MIN})$$

$$\text{PID Output} = K p \times \text{Error} + K d \times (\text{Error} - \text{Last\ Error})$$

#### 工况 A：直道与微弯 (|Error| < 2.0)

$$\begin{cases} \text{Left Motor} = \text{Current Base} + \text{PID Output} \\ \text{Right Motor} = \text{Current Base} - \text{PID Output} \end{cases}$$

#### 工况 B：中度弯道 (2.0 <= |Error| < 4.0)

$$\begin{cases} \text{Left Motor} = \text{Current Base} + 120,\; \text{Right Motor} = -90 & (\text{Error} > 0) \\ \text{Left Motor} = -90,\; \text{Right Motor} = \text{Current Base} + 120 & (\text{Error} < 0) \end{cases}$$

#### 工况 C：急弯大弧线 (|Error| >= 4.0)

$$\begin{cases} \text{Left Motor} = 380,\; \text{Right Motor} = -180 & (\text{Error} > 0) \\ \text{Left Motor} = -180,\; \text{Right Motor} = 380 & (\text{Error} < 0) \end{cases}$$
### 2. 核心运行参数标定基准表

| 控制维度 | 参数宏定义 | 生产标定值 | 物理作用机制与调参准则 |
| --- | --- | --- | --- |
| **直道巡航极速** | `SPEED_BASE` | `450` | 直道开环基准速度，若供电电压充足可向上微调至 480 |
| **入弯最低底速** | `SPEED_CURVE_MIN` | `90` | 极限减速保护阈值，不可低于 70，防止落入电机摩擦死区 |
| **自适应降速梯度** | `SPEED_DROP_RATE` | `50` | 偏航降速灵敏度，数值越大入弯降速越迅猛 |
| **PD 比例系数** | `KP` | `42.0f` | 主导小偏航快速响应，过大会引起直道高频振荡抖动 |
| **PD 微分系数** | `KD` | `75.0f` | 抑制入弯姿态发散与过冲，过大会放大传感器量化噪声 |

| **避障超越时间** | `TIME_FORWARD_PASS` | `460` (ms) | 控制纵向越障距离，确保完全越过障碍物侧方投影面 |
| **避障回切时间** | `TIME_TURN_LEFT` | `430` (ms) | 决定回转角速度，与单侧轮配合形成小夹角斜切 |
| **触线冲正时间** | `TIME_PULL_STRAIGHT` | `180` (ms) | 触线后反向打舵时间，消除向左角动量，实现车身拉直 |

## 七、 硬件工程落地避坑指南

1. **CRL 寄存器复用推挽覆盖规则**：
* 配置特定引脚模式前，必须对该引脚在 `CRL`/`CRH` 中的 4 个对应位（`MODE` 和 `CNF`）彻底清零。若直接执行按位或操作，会导致原寄存器残留的高电平位产生冲突，使复用推挽（`0xB`）退化为通用输入或开漏模式。


2. **超声波测距分频与循迹主频解耦**：
* HC-SR04 在检测到超距或无障碍物时，回波高电平最大持续时间可达数十毫秒。若直接置于循迹主循环中串行等待，会导致控制周期严重拉长，直接摧毁微分项（$K_d$）的时序连续性。
* **工程解法**：在主循环中设置计数器分频器，每迭代 10 次（约 30~40ms）执行一次测距，其余迭代专心维持 2ms 高频精确循迹。


3. **单片机与外设严格单点共地**：
* L298N 驱动板的强电地（GND）、电池负极、红外传感器地与单片机开发板的 GND 必须可靠物理互联。共地阻抗过大会导致电机启停的大电流在信号地线上产生几百毫伏的杂波反峰，导致单片机异常复位或超声波误判。


4. **探头离地垂直高度控制**：
* 4 路红外探头离地高度必须严格卡控在 **8mm ~ 15mm**。过高会导致反射光斑严重发散，信噪比恶化直接落入全白盲区；过低则易在下坡颠簸时撞击跑道机械断裂。


5. **动力电池供电内阻与压降补偿**：
* L298N 内部达林顿管压降在全速运行下约为 1.5V~2.0V。当电池放电至标称 7.4V 以下时，降速档位输出的实际端电压极低，易陷入静摩擦死区。赛道调试应确保电池电压维持在 **8.0V 以上**，以保证时间延时与转向角度的高度重合。

# STM32F103 智能避障小车 (寄存器版本)

基于 STM32F103ZET6 开发板、L298N 电机驱动模块与 HC-SR04 超声波传感器的寄存器级 DIY 智能小车控制程序。

## 硬件接线表

### 1. L298N 电机驱动
| L298N 引脚 | STM32 引脚 | 功能说明 |
| :--- | :--- | :--- |
| **ENA** | `PA6` | 左轮 PWM 调速 (`TIM3_CH1`) |
| **ENB** | `PA7` | 右轮 PWM 调速 (`TIM3_CH2`) |
| **IN1** | `PA0` | 左轮方向控制 |
| **IN2** | `PA1` | 左轮方向控制 |
| **IN3** | `PA4` | 右轮方向控制 |
| **IN4** | `PA5` | 右轮方向控制 |
| **GND** | `GND` | 共地 |

### 2. HC-SR04 超声波测距
| 超声波引脚 | STM32 引脚 | 功能说明 |
| :--- | :--- | :--- |
| **Trig** | `PB10` | 触发测距 (推挽输出) |
| **Echo** | `PB11` | 回响信号 (下拉输入) |
| **VCC**  | `5V`   | 供电 (必须 5V) |
| **GND**  | `GND`  | 信号地 |

### 3. 板载外设与状态指示
* **LED0 (`PE5`)**: 遇到障碍物探路时点亮，正常直行时熄灭。
* **蜂鸣器 (`PB8`)**: 默认输出低电平静音，避开硬件引脚冲突。

## 避障逻辑
1. 前方检测到障碍物 ($\le 5\text{ cm}$) 时，小车立即刹停。
2. 小车原地向左旋转 45° 探测左侧距离，随后向右旋转 90° 探测右侧距离。
3. 比较左右距离，选择更宽敞的方向脱困并继续前进。

# STM32F103 智能避障与高速循迹小车 (寄存器版本)

本项目基于 **正点原子 STM32F103ZET6 精英板**、**L298N 电机驱动模块**、**HC-SR04 超声波测距模块** 与 **4 路红外循迹传感器**，采用**纯底层寄存器级代码**构建。系统集成了 1kHz 硬件 PWM 差速调速、高精度超声波微秒测距、断崖式入弯自适应减速与动量抑制算法、急弯向心主动反拉力矩、历史偏航记忆抗冲线自救，以及带**主动倒车缓冲与大横向安全间距**的复合闭环避障状态机。

## 二、 代码文件结构与说明

本项目根据功能模块解耦与渐进式开发原则，划分了各个阶段的测试与集成代码文件：

### 1. `四轮前进.c`（基础电机驱动验证）
* **功能说明**：最基础的双侧电机 GPIO 电平控制。
* **主要验证**：排查 L298N 供电线路、逻辑引脚接线方向以及双侧车轮正反转极性是否一致。

### 2. `差速测试.c`（TIM3 硬件 PWM 差速调速）
* **功能说明**：配置 `TIM3` 通道 1 (`PA6`) 与通道 2 (`PA7`) 输出 1kHz 硬件 PWM。
* **主要验证**：实现 `Motor_SetSpeed(speedLeft, speedRight)` 函数，测试左右轮独立调速、原地自转及差速过弯性能。

### 3. `循迹.c`（4 路红外自主循线）
* **功能说明**：实现 4 位红外探头（PC0~PC3）的状态机扫描与差速转向修正。
* **主要验证**：验证直行居中、微偏微调、急弯大差速打舵以及应对大曲率弯道的稳定性，锁定基准巡航速度。

### 4. `超声波模块测试（配合LED灯）.c`（传感器独立硬件诊断）
* **功能说明**：**完全不启动电机**，排除电机启停瞬间的大电流反峰干扰。
* **诊断指示**：
  * **LED0 快速闪烁**：硬件故障 / 供电不足 5V / 超声波未收到有效回波。
  * **手靠近探头 10cm 内 LED0 常亮，移开后熄灭**：证明超声波模块驱动与微秒脉宽捕获 100% 正常。

### 5. `超声波测距停车.c`（静态遇障紧急制动）
* **功能说明**：小车直线巡航，前方检测到障碍物距离 $\le 5\text{ cm}$ 时立即刹车停车；障碍物移开后自动恢复前行。
* **主要验证**：验证超声波在动态行进中的测距稳定性以及紧急刹停的响应延迟。

### 6. `循迹+超声波停车.c`（循线巡航与动态防撞集成）
* **功能说明**：将 4 路红外循迹与超声波测距融合。小车沿黑线自主巡线，当前方轨道出现障碍物时，立即暂停电机循线并在原地刹停等待；障碍物移走后自动无缝继续循线。

### 7. `避障绕行.c`（小夹角绕障姿态单项标定）
* **功能说明**：**剥离常规循迹控制**，专用于单项标定小车的绕障轨迹与动作时间。
* **主要验证**：小车遇障后依次执行动作，抓到黑线并拉直车身后**立即原地刹停锁死**，便于肉眼观察入轨姿态与切角是否达标。

### 8. `循迹+避障绕行1.0.0.c`（全闭环自主巡航与避障系统）
* **功能说明**：将验证成熟的循迹逻辑与避障绕行流程深度融合。
* **运行机制**：平时以固定速度稳定循线；遇障触发紧凑绕行，绕过障碍重新捕获黑线后，自动切换回常规循线状态，实现无需人工干预的自主避障闭环。

### 9. `循迹+避障绕行2.0.0（终极高速高机动版）.c`（当前主力工程代码）
* **功能说明**：集成了**极速直道冲刺（PWM 450）**、**断崖式入弯自适应阻尼降速**、**带倒车缓冲的大间距避障绕行**与**小夹角顺线拉直**的终极工程版本。彻底消除了传统循迹小车直道慢、急弯甩尾冲出赛道及避障剐蹭障碍物等顽疾。

## 三、 近期核心技术攻关与软硬件故障诊断记录

### 1. 电机驱动底层 `GPIOA->CRL` 掩码错误排查（单侧轮不转根因）
* **故障现象**：在调试过程中偶现“右轮正常旋转，而左轮完全不转”或“单侧轮锁死空转”。
* **根因定位**：`Motor_Init()` 中对 `GPIOA->CRL` 的清零掩码配置错误：
  ```c
  // 错误写法：未能彻底清空 PA6 对应位，导致模式位错位覆盖
  GPIOA->CRL &= 0x0000FF00;
  GPIOA->CRL |= 0xBB330033;

```

该错误导致控制左轮 PWM 的 `PA6`（TIM3_CH1）未能成功进入“复用推挽输出（AF-PP）”模式，输出被芯片内部下拉钳死，PWM 无法送达 L298N 的 ENA 端。

* **终极修正**：严格规范寄存器配置，使用原子级标准掩码：
```c
GPIOA->CRL &= 0x0000FF00; // 彻底锁定对应控制位
GPIOA->CRL |= 0xBB330033; // PA0,PA1,PA4,PA5通用推挽(0x3)，PA6,PA7复用推挽(0xB)

```



### 2. 红外探头硬件物理损坏与软件容错策略

* **故障现象**：3 号探头（PC1 / IN3）调节电位器时指示灯呈现“要么常亮、要么常灭”，遮挡完全不发生跳变；无论地面如何变化均输出固定错误电平。
* **硬件诊断**：利用手机摄像头红外滤镜排查，确认 1、2、4 号探头能看到正常的粉紫色红外光，而 3 号探头发射管完全无光，确认为硬件级发射二极管/限流电阻断路烧损。
* **软件容错保障**：
* 在宽黑线（3~4 条胶带拼接，宽 50~60mm）环境下，重构了偏差提取逻辑与状态容错表。
* 引入 `memory_dir`（偏航记忆），在探头因瞬态晃动跳变时提供稳定的方向锁存，防止单侧轮突发减速锁死。



### 3. 下坡长直道冲刺与小半径急弯（直角弯）矛盾化解

* **现象**：赛道存在长直道紧接小半径急弯（如跑道左下角急弯）。若采用传统线性 PD 控制，直道极速行驶时的巨大切线动量在进入小半径弯道时无法被迅速抵消，车身会因离心力直接甩飞出跑道。
* **控制算法革新（动量抑制与主动反拉机制）**：
* **断崖式自适应降速**：基础巡航提升至 `SPEED_BASE = 450`；一旦探头感知到偏航，巡航基准按斜率 `SPEED_DROP_RATE = 50` 呈断崖式迅速跌落至 `SPEED_CURVE_MIN = 90`，在入弯前 10~20ms 内强制踩下“电子刹车”。
* **急弯主动向心反拉**：当绝对偏差 $\vert{}Error\vert{} \ge 4.0$ 时，不仅外侧轮给足推力（`380`），内侧轮更施加 **`-180` 的负向反转力矩**，强行把车头“拽”向弯道内侧，彻底化解甩尾惯性。
* **中弯动力阻尼**：$2.0 \le \vert{}Error\vert{} < 4.0$ 时，内侧轮施加 `-90` 的轻度反转阻尼，防止车身切线冲线。



### 4. 避障防剐蹭与平缓小夹角入轨（七阶段避障状态机）

* **现象**：单纯使用正向打舵避障时，由于小车以 450 的高速冲刺，刹停后右打舵距离过小导致车身右侧直接剐蹭障碍物；且回切至黑线时车头夹角过大（接近垂直），导致直接“冲穿”跑道。
* **避障状态机优化**：
1. **倒车物理缓冲**：遇障检测到 $\le 12\text{ cm}$ 后，先刹车制动，紧接着执行 **150ms 的短促倒车（`-450, -450`）**，主动与障碍物拉开物理裕量。
2. **增大横向净距**：向右大差速借道打舵加长至 320ms（`460, 80`），纵向超越加长至 590ms，彻底避开障碍物轮廓。
3. **动量预制动回切**：回切前先给 20ms 的瞬间反抽制动（`-300, 200`）抑制右甩角动量，随后单侧推进（`0, 460` 持续 430ms），以 **$25^\circ \sim 35^\circ$ 的平缓小锐角**切入原赛道。
4. **触线反向冲正**：双重采样确认踩中黑线后，执行 180ms 的反向小打舵（`260, 80`），在切线方向将车身瞬间拉直，平稳无缝切回 PID 闭环。

## 六、 硬件调试与避坑要点指南

1. **CRL 寄存器复用位覆盖陷阱**：
* 在使用纯寄存器配置 GPIO 引脚模式时，必须先将对应引脚的 4 个控制位彻底清零，再执行按位或运算写入目标配置。若清零掩码不彻底，复用推挽（`0xB`）无法生效，引脚会被固定在低电平或输入态。


2. **超声波测距分频机制**：
* HC-SR04 超声波测距内部有微秒级的电平等待，若在每个循迹循环中无节制调用，会导致小车循迹控制周期被拉长至数十毫秒，直接破坏微分项（$K_d$）的时序连续性。
* **解决方案**：在 `main` 循环中引入计数器，每循环 10 次（约 30~40ms）执行一次 `Get_Distance()`，既保证了避障的灵敏响应，又锁死了循迹 2ms 的高刷新率。


3. **超声波引脚抗干扰规范**：
* 严禁将超声波引脚映射至与板载外设冲突的引脚（如 `PB8` 蜂鸣器或 `PB5` LED1）。本项目统一定位在独立 GPIO `PB10` (Trig) 与 `PB11` (Echo)。


4. **探头高度与环境光校准**：
* 红外探头对地垂直高度应保持在 **8mm ~ 15mm** 之间。高度过高会导致发射光斑过大、反射弱，探头频繁落入 `0b0000`（全白地）；高度过低容易在车身颠簸时剐蹭地面导致引脚断裂。


5. **电机死区与供电保护**：
* L298N 具有约 1.5V~2.0V 的内部压降。当电池放电至 7.4V 以下时，给定的低速档位（如 60~80）可能无法驱动小车克服地面静摩擦力。调试时建议电池电压保持在 **8.0V 以上**，以获得稳定一致的转向与入轨动作。
